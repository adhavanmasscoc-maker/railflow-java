Operations FAQ

Questions,
answered

Technical questions about Core Java algorithms, platform reallocations, and database schemas.

How does RailFlow achieve 0.15 ms timetable queries?
+
RailFlow indexes 6,675+ active express corridors in contiguous in-memory arrays and executes an optimized binary search ($O(\log N)$). Because the dataset is pre-sorted and mapped, queries execute in approximately 0.15 ms without incurring remote network latency.
How does the Max-Heap platform optimization prevent stampedes?
+
Each terminal track platform is modeled with capacity limits and categorized into four safety tiers (`EMPTY`, `NORMAL`, `WARNING`, `CRITICAL`). A `PriorityQueue` Max-Heap constantly bubbles up the most congested platforms ($O(N \log K)$), allowing the dispatch system to reroute incoming rakes to adjacent vacant tracks before platform occupancy reaches critical thresholds.
Can RailFlow operate fully offline at remote stations?
+
Yes. RailFlow embeds a 102.69 MB SQLite database (`database/railway.db`) with Write-Ahead Logging (WAL). All 13,849 operational records, station hierarchies, and train timetables reside directly on local disk, ensuring uninterrupted command operations even if external internet or cloud backhauls are severed.
How are colloquial station names resolved?
+
RailFlow incorporates a Canonical Alias Dictionary with 9,456 colloquial names and historic city aliases. Typing informal search strings like "trichy", "madras", or "calcutta" automatically resolves in $O(1)$ to standard IR station codes (`TPJ`, `MAS`/`MS`, `HWH`).
What are the system requirements to run the engine?
+
The backend requires Java 21 LTS or newer. Memory footprint is lightweight (~120 MB RAM) thanks to embedded SQLite and in-memory heap structures. The web dashboard runs smoothly on any modern browser supporting HTML5 and CSS Grid.
Is the source code open and verifiable?
+
Yes. The complete repository, test suite (20/20 JUnit 5 tests), architecture specification, and academic build history chronicle are open source under the MIT License on GitHub.

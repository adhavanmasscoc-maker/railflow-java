🎬 RailFlow Interactive Operations Guide
Welcome to RailFlow — a realistic Core Java-powered Railway Station Intelligence & Platform Optimization Platform!
1. 📊 Live Dashboard & Operations: Watch real-time concurrency ticks update platform density meters, hourly footfall charts, and train arrivals.
2. 🚨 Test Crowd Overload: Click any Platform card (e.g., Platform 1), enter crowd footfall of 550, and click Apply Crowd Load. The system instantly detects critical density (≥90%) and dispatches emergency alerts!
3. ⚡ Heuristic Optimizer: Navigate to Platform Optimizer to see PriorityQueue binary heap ranking and click Apply to redistribute commuter streams.
4. 🔍 Global Search ($O(\log N)$): Search any train number (e.g., 12301, 12951) or station (NDLS, MAS) in the top search bar.
5. 📁 22.1 MB CSV Explorer: Explore multi-decade Indian Railways statistics spanning 1970–2013+ across Broad Gauge, Metre Gauge, and Narrow Gauge networks.
6. ☕ Core Java Architecture: Explore the 23 OOP, Multithreading, and Stream API concepts powering the core engine.
